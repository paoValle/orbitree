# 3. The name: Orbitree

- **Status**: accepted
- **Date**: 2026-10-09 (the third name, and the one that ships: all three before any release)

## Context

The project was started under the name of the directory it was created in, and that name did not
survive a search. It is worth keeping the record, because both earlier names were plausible and the
reasons they failed are the reasons the check exists.

| | Why it failed |
|---|---|
| `octogit` | Three unrelated projects already use it: a Python CLI on PyPI, an npm wrapper around octokit, and a git helper on GitHub. `octo-` also reads as another company's branding in a product that is deliberately forge-agnostic. |
| `Keplerk` | It passed its checks and was adopted, then dropped the same day. Kepler is a busy name in adjacent markets, and it says nothing about what the product does. |
| **`Orbitree`** | Names both halves of the picture: the orbits a commit graph draws, and the tree the commits form. |

## The check that was run

| Check | Result |
|---|---|
| `npm view orbitree` | `E404`, and `npm search orbitree` finds nothing. The name was published once and unpublished on 2022-06-23, so the registry entry is free. |
| PyPI | `404` |
| GitHub repository search | 2 results, `OrbitReel` and `OrbitReels`, both unrelated and unstarred. No `orbitree`. |
| Trademark search | **still outstanding.** It blocks a release (roadmap P7), not the work. |

## Consequences

The name is load-bearing in exactly four places, which is why this rename is a `perl -pi -e` over the
tracked files plus a `git mv`:

- `APP_NAME` in `packages/core/src/index.ts`;
- the package scope, `@orbitree/{core,cli,desktop}`, and `orbitree-workspace` in the workspace files;
- the executable, `bin/orbitree`;
- `appId: dev.orbitree.app` and `productName: orbitree` for the installer.

Two leftovers are part of the rename and were removed rather than forgotten:

- Electron's user-data directory is derived from the `appId`, so the app had already created
  `~/Library/Application Support/@keplerk`. Nothing regenerates it once the name changes, so it is
  residue by definition.
- a temporary `octogit` symlink existed only because a session had been started with the old
  directory as its working directory.

Both earlier names are written down here so that a future reader does not reintroduce them.
