# 3. The name: Keplerk

- **Status**: accepted
- **Date**: 2026-10-09 (decided the same day, before the first release)

## Context

The project was started under the working name `octogit`, borrowed from the directory it was
created in. Before anything was published, the name was checked, and it does not survive:

| Existing project | What it is |
|---|---|
| `myusuf3/octogit` | a Python CLI for GitHub issues, published on PyPI as `octogit` |
| `KnisterPeter/octogit` | an npm package wrapping octokit and git |
| `Axlefublr/octogit` | a git helper in the same space |

A name search would put this project's repository fourth in a list of unrelated tools, and the
npm package of the same name belongs to somebody else. On top of that, `octo-` reads as a
reference to another company's branding, which is an unnecessary association for a product that is
deliberately forge-agnostic.

## Decision

**Keplerk.**

- *Kepler*: orbits, ellipses, bodies moving through a shared space — which is what a commit graph
  looks like when it is drawn well, and what the product's centrepiece is.
- *fork*: the trailing `k` carries the `k` of a fork in most of the spelling conventions around
  it (`gh`, `k8s`), and a fork is the shape the product spends its time drawing.
- Short, pronounceable in one go, no hyphen, no digits, and it does not name a forge.

## The check that was run

| Check | Result |
|---|---|
| `npm view keplerk version` | not published |
| GitHub repository search | no project of this name |
| PyPI | not published |
| Trademark search | **not yet run** — required before the first published artifact (roadmap P7) |

The last row is the open one. It does not block the work: it blocks a release, and it is cheaper
to run once there is something to release.

## Consequences

The rename was mechanical because the name was never load-bearing in more than two places:

- the display name: `APP_NAME` in `packages/core/src/index.ts`;
- the package scope: `@keplerk/{core,cli,desktop}` and `keplerk-workspace` in four `package.json`
  files, plus the workspace entries in `pnpm-lock.yaml`;
- the executable: `bin/keplerk`;
- prose in this documentation, and `appId: dev.keplerk.app` for the installer.

One `perl -pi -e 's/octogit/keplerk/g'` over the tracked files, a `git mv` of the script, a
`pnpm install` to relink the workspace, and `make verify` to prove nothing moved that should not
have. That is the whole cost, and this time it was paid before a single release instead of after.
