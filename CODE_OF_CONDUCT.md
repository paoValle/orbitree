# Code of conduct

## The short version

Be decent. This project is a place where people with very different levels of git experience
work on the same code: nobody is expected to know a command by heart, and nobody is expected to
explain the same thing twice with the same patience.

## Expected

- Assume competence and good faith. Disagree with the change, not with the person.
- Ask when you do not understand, and answer when you do.
- Keep review comments about the code, and say plainly what would make the change acceptable.
- Accept that a maintainer's "no" is allowed, and that it comes with a reason.

## Not acceptable

- Harassment of any kind, or language that makes a space hostile for anyone by gender, gender
  identity, sexual orientation, disability, appearance, body size, race, ethnicity, religion or
  level of experience.
- Insults, personal attacks, or dismissing a contribution because of who wrote it.
- Sustained disruption of discussions, including reopening a settled decision without new
  information.
- Publishing someone's private information without permission.

## Scope

Issues, pull requests, reviews, commit messages, and any space where someone is representing the
project.

## Enforcement

Report it privately to the maintainer (`@paoValle`), including what happened and what would help.
Reports are handled confidentially. Depending on severity, the response is a private word, a
public correction, temporary exclusion from the repository, or a permanent ban.

Nothing here requires a process: if something feels wrong, saying so in the issue is fine, and
withdrawing a comment is fine too.
